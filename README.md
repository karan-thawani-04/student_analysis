# 🎓 Student Data Analysis Project

This project analyzes student performance using Python. It includes data cleaning, analysis, and visualization using real-world dataset concepts.

---

## 📌 Features

- 📊 Data Loading using Pandas
- 🧹 Handling Missing Values
- 📈 Student Performance Analysis
- 🏆 Top 5 Students Identification
- 📉 Data Visualization (Study Hours vs Marks)

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

---

## 📂 Project Structure

student-analysis/
│
├── project.py          # Data analysis
├── graph.py            # Visualization
├── student_dataset_v2.csv
├── requirements.txt
└── README.md

---

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run analysis:
   python project.py

3. Run graph:
   python graph.py

---

## 📊 Sample Output

- Displays dataset info
- Shows missing values
- Prints top 5 students
- Generates scatter plot (Study Hours vs Marks)
